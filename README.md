# SEU·绩点计算器

**直接登录教务账号，自动获取成绩、学分并计算绩点，无需逐门手动输入。**

| 成绩获取方式 | 说明 |
| --- | --- |
| **账号登录（推荐）** | 点击“登录并获取成绩”，输入统一认证账号和密码即可自动获取；学校要求时按提示完成短信验证。 |
| 导入已有成绩 | 导入 JSON 备份、本程序导出的 CSV，或粘贴教务 JSON 返回包。 |
| 手动补充 | 点击“添加课程”，填写课程名称、成绩和学分。 |

- **绩点与均分**：同时显示 4.0 / 4.8 制 GPA、加权均分和均分对应参考绩点，方便对比“卡绩”影响。采用分段换算，不插值；4.0 制中，90 分及以上统一为 4.0。
- **课程管理与分析**：支持搜索筛选、编辑课程、计入或排除课程，查看成绩分布与学期对照；统计随筛选范围更新。
- **目标均分预测**：输入目标总均分和未来学分，计算后续课程需要达到的均分。

安装 Python 3.10+（含 Tkinter）和联网依赖：

```powershell
python -m pip install requests
```

双击 `SEU·绩点计算器.bat` 打开，也可运行 `python "SEU·绩点计算器.py"`。

点击“保存记录”或按 `Ctrl+S` 才会生成 `log/日期_时间.json`，每次一份，下次启动恢复最近一次保存。`log` 文件夹可直接删除，下次保存时自动重建。

支持导出 JSON 备份、CSV 表格和 TXT 成绩报告。

获取失败时，请检查 VPN / 代理设置是否影响教务访问。
